# 부품 제조사 문의 초안 — C03 내부 수납용 치수/전기 확인

**발송 전 각 업체·SKU에 맞게 제목과 해당 문항만 남길 것. 아직 발송하지 않음.** Dell Inspiron 15 3525 교체 하판의 고정 쐐기 외형은 340×215×20 mm이고, 현재 연구 CAD의 후방 내부 높이 상한은 `13−(16/215)×Y` mm(Y는 부품/케이블의 후방 끝이 아니라 쐐기 뒤 기준부터 가장 앞 끝까지). 실물 조립 여유와 단열·고정 공간은 이 상한에서 추가로 빠진다. PCB만의 높이나 케이스만의 크기는 불충분하다.

## 공통 요청 문안

안녕하세요. 아래 정확한 모델/리비전을 제한 높이의 프로젝트 하우징에 넣을 예정입니다. 발주 전 다음을 **mm 단위 치수도 또는 STEP**과 함께 확인 부탁드립니다.

1. 출하 상태 완제품의 최대 X×Y×Z, 공차, 가장 높은 부품/커넥터 위치. 케이스가 있으면 케이스 포함/제거 각각. 제조사가 케이스 제거 사용을 허용하는지도 명시해 주세요.
2. 실제 사용 시 모든 HDMI/eDP/USB/전원/FFC 플러그를 꽂은 상태의 3D 점유공간, 커넥터 방향, 최소 케이블 굽힘 반경, 스트레인 릴리프 요구.
3. 장착홀 XY/지름, PCB 하부 부품 높이, 필요한 절연 거리·통풍 공간 및 허용 장착 방향.
4. 정상/최대 소비전력과 테스트 조건, 동작 온도 범위, 방열 요구 및 밀폐 케이스 내 사용 가능 여부.
5. 리비전별 회로·펌웨어 차이, 문서 번호, 이 수치가 적용되는 정확한 판매 SKU.
