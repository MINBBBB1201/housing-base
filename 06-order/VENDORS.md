# 외주 제작 조사 — 중국 (2026-09-24)

전제: **전량 외주** (사용자 결정). 3D 프린트에 한정하지 않음.
중국 업체는 한국어 사이트가 없어 이 문서만 중국어 사이트로 조사함.
용어: 노트북 하판 = **D壳** (A壳 상판 뒷면, B壳 베젤, C壳 팜레스트, D壳 하판).

## 1. 업종 구분

| 업종 | 중국어 | 하는 일 | 우리 적합도 |
|---|---|---|---|
| **시제품 공장** | 手板厂 | **抄数**(실물 3D 스캔 역설계) → 설계 수정 → CNC/SLA/SLS 가공 → 도장·인쇄 → 소량 조립까지 한 번에 | ★★★ **1순위.** 실측·모델링·후가공을 한 곳에 맡길 수 있음 |
| **온라인 3D 프린트 플랫폼** | 在线3D打印 | CAD 파일을 올리면 즉시 견적·출력 | ★★ CAD가 완성된 뒤 싸고 빠른 반복 출력용 |
| **금형·사출 제조사** | 模具/注塑厂 | 금형 제작 → 대량 사출 | ★ 수백 개 이상일 때만. 1~10개에는 과함 |

## 3. 제작 방식 비교 (하판 1~10개 기준)

| 방식 | 재질 | 장점 | 단점 | 판단 |
|---|---|---|---|---|
| **SLA 수지** | 광경화 수지 | 정밀(±0.2), 표면 매끈, 도장 쉬움 | **충격·스냅 클립에 약함**, 열·자외선에 약해질 수 있음 [추정] | 맞춤 확인용 시제품 |
| **MJF/SLS 나일론 PA12** | PA12 | **질기고 스냅 클립에 강함**, 내열 양호 [추정] | 표면이 약간 거칢, 정밀 ±0.3 | **실사용 1순위** |
| **CNC (ABS/PC 블록)** | ABS, PC | OEM 사출품과 가장 비슷한 재질·강도 | 비쌈, 안쪽 리브·후크 가공이 까다로움 | 예산 여유 시 |
| **复模 (실리콘 몰드 진공주형)** | PU 수지 (ABS 유사) | 1개 원본으로 10~30개 복제 | 원본(마스터)이 먼저 필요 | 여러 대 만들 때 |
| 금형 사출 | PC/ABS | OEM과 동일 | 금형비가 큼 | 대량일 때만 |

## 4. 권장 발주 흐름 [추정]

1. 淘宝/1688에서 **예비 OEM 하판 03JRFX를 1개 구매** → 手板厂에 **스캔용 샘플**로 보냄 (사용 중인 노트북 하판은 보내지 않음)
2. 手板厂에 **抄数 (3D 스캔 역설계)** 의뢰 → OEM과 동일한 CAD(STEP) 확보. 우리 사진 추정값(`../02-measure/MEASURE-TABLE.md`)은 검수 기준으로 사용
3. 우리 요구사항 문서 전달: 외부 쐐기 형상, 흡기 유로, 추가 내부 공간, 금속 박 재부착, 나사·captive 유지 → **업체가 설계 수정** 또는 우리가 수정
4. **SLA 1개로 맞춤 확인** (나사 8개, 클립, 힌지 홈, 흡기) → 수정
5. **MJF PA12 (또는 CNC)로 실사용품** 제작, 도장·금속 박·고무발 후가공까지 업체에 포함
6. 여러 대면 이 결과물을 마스터로 **复模**

## 5. 업체에 물어볼 것 (견적 요청 템플릿 초안)

- 抄数 가능 여부, 스캔 정밀도, 결과물 형식 (STEP)
- 스캔 CAD 기반 설계 수정 대행 가능 여부
- 재질별 (SLA / PA12 / CNC ABS) 단가와 납기
- 스냅 클립(외곽 후크) 재현 경험, 최소 두께
- 후가공: 무광 흑색 도장, 내부 도전성 박 부착, 고무발, M2 인서트
- 해외(한국) 배송 가능 여부 또는 중국 내 수령 주소 필요 여부
