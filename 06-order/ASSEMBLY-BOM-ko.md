## 1. 4일 안에 도착 가능한가

**결론: 보장할 수 없고, 나일론(PA12)은 가능성이 낮다. 가장 빠른 것은 JLC 내열 레진(JLCTemp) 24시간 납기이며, 결제 전에 업체에게 "9/30 전 발송"을 확답받아야 한다.**

| 사실 | 출처 |
|---|---|
| 오늘 9/26(토)은 중추절 연휴(9/25~27). 평일은 9/28~30뿐. **국경절 연휴 10/1~7** | [국무원 2026 휴일 안내 요약](https://www.sohu.com/a/1078315209_121123831) |
| JLC 3D는 2023년 중추·국경 연휴 5일 동안 **전원 휴무**, 주문은 받지만 납기가 연휴만큼 밀림 | [JLC 2023 연휴 공지](https://www.jlc.com/portal/q7i41502.html) |
| 24시간 납기 = 오늘 19시 전 결제 → 내일 20시 전 발송. 48시간 = 모레 20시 전 발송. **이형·대형 부품 +1~2일** | [JLC 下单前必看](https://www.jlc-3dp.cn/technicalColumnsDetails/40026.html) |
| PA12-HP: 최대 370×276×360 mm, 공차 ±0.3 mm(100 mm 이내)/±0.4 %, 최소 벽 1 mm, 원색 회색 | [JLC PA12-HP](https://jlc3dp.com/help/article/pa12-hp-nylon) |
| 나일론 기본 48~72시간, 검정은 염색 후가공 | [JLC 제작 기간](https://jlc3dp.com/help/article/what-is-the-build-time-of-the-3d-printing-parts), [PA12S](https://www.jlc-3dp.cn/technicalColumnsDetails/60681.html) |
| JLCTemp 레진: 열변형 101 °C, Tg 130 °C, **24시간 납기**, 인성 보통 | [JLCTemp](https://www.jlc-3dp.cn/technicalColumnsDetails/61612.html) |
| 8228 레진: 열변형 56.4 °C → 노트북 아래 3시간 사용에는 부적합 | [JLC 8228](https://www.bilibili.com/video/BV1wN4y1Q7k9/) |

| 선택 | 9/30까지 도착 가능성 | 장점 | 단점 |
|---|---|---|---|
| **A. PA12 나일론 MJF, 회색 원색** | 낮음. 주말 생산이 없으면 월요일 시작 → 48~72 h + 대형 1~2일 → 10/1 이후 발송 → 연휴 뒤 도착 | 후크·스냅이 잘 안 부러짐, 내열 여유 큼, 무게 약 318 g | 일정 |
| A′. PA12 검정 염색 | 더 낮음 (염색 +α) | 순정과 색이 같음 | 일정 |
| **B. JLCTemp 내열 레진** | 중간. 24 h + 대형 1~2일이면 9/29~10/1 발송 | 가장 빠름, 표면 매끈, 열 101 °C | 후크(1 mm)·스냅이 부러질 수 있음 → 부러지면 나사 8개와 선택용 뚜껑 나사로 대신 |
| C. 두 곳에 동시 주문 (B + A) | B가 제때 오면 사용, A는 연휴 뒤 정식품 | 일정 위험 분산 | 비용 약 2배 |

권장 순서: ① 지금 업로드해 두 재질 견적·납기를 받는다(결제는 보류). ② 고객센터(在线客服)에 "中秋期间是否生产, 能否9月29日前发顺丰" 확인. ③ 확답이 있는 쪽으로 결제. ④ 발송은 순풍(顺丰) 익일 도착 지정. 무게는 PA12 약 318 g, 레진 약 362 g. 이전 조사 기준 JLC PA12 단가 1.55위안/g(세금 별도) → 약 490위안 + 세금. 레진 가격은 업로드 즉시 견적으로 확인.

### F. 배선 (v4 전자부품 쪽에서 확정)

쐐기 안 높이는 뒤쪽 약 13 mm이고 앞으로 갈수록 낮다. 일반 HDMI 플러그(두께 약 11~12 mm)와 현재 후보 분배기(13.98)·USB3 캡처(12.65)는 들어가지 않는다 → 두꺼운 장치는 **왼쪽 케이블 창으로 빼서 외부에** 두거나, 얇은 FFC형 HDMI(`HDMI 软排线 FPV` + `HDMI 弯头转接头`)와 얇은 부품으로 바꾼다. eDP 인터포저·케이블은 v4 핀맵 확정 후 결정한다.

## 3. 조립 순서 (요약)

1. **수령 검사**: 평판 위 네 모서리 들뜸, 나사 구멍 8개 관통, 후크 13개 파손, 분말 잔류, 뚜껑 스냅 끼움·빠짐.
2. 노트북 전원 끄고 충전기 분리 → Dell 절차대로 순정 하판 분리(captive 2개는 풀기만, M2×5 6개 보관) → **배터리 커넥터 분리**.
3. **전자부품 없이** 새 하판을 뒤(힌지) 쪽부터 대고 앞으로 눌러 닫는다. 억지로 누르지 않는다. 걸려서 뜨는 후크는 니퍼로 잘라 낸다.
4. 나사: 뒤 3곳 M2×8, 앞 3곳 M2×6, 옆 2곳 순정 M2×5, 모두 평와셔. 손힘으로 가볍게.
5. 배터리 연결 → 전원 → 키보드·터치패드·포트(HDMI·USB·SD·DC)·팬 확인. 측면 포트에 플러그가 끝까지 들어가는지 꼭 본다.
6. 다시 분리해 쐐기 안에 전자부품 장착: 절연 시트 → 폼테이프 → 선 정리 → DC 잭·GPIO 보드 → eDP 케이블 지붕 통로.
7. 뚜껑을 스냅으로 끼운다. 첫 사용은 30분 저부하로 온도·냄새·소음 확인 후 3시간.
