# 국내 3D 스캔 의뢰 (사용자 무접촉 경로) — 2026-09-26 초안

**초안이다. 발송·결제 전에 사용자가 내용을 확인한다.** 중국에서 스캔·역설계·출력·시험조립을 한 번에 맡기는 경로는 [`RFQ-zh.md`](RFQ-zh.md)(업체 현지 샘플 대리구매 조항 포함)를 쓴다. 이 문서는 **스캔 메시만 국내에서 받는** 경로다.

## 경로 비교

| | A. 중국 일괄 ([RFQ-zh.md](RFQ-zh.md)) | B. 국내 스캔만 (이 문서) |

| 업체가 하는 일 | 샘플 대리구매 → 스캔 → STEP 역설계 → 수정 → 출력 → 팜레스트 시험조립 | 스캔 → STL 메시 |
| 사용자가 하는 일 | 견적 요청 발송, 결제 | 부품 주문(업체 주소로 배송), 의뢰 메시지 발송, 결제 |
| 비용 | 약 ¥3,000~7,000 + 샘플비 ([ESTIMATE.md](ESTIMATE.md), 추정) | 부품 약 $42 + 스캔 30만 원~ (공개가, 역설계 별도) |
| 이후 작업 | 업체 STEP 수령 | 메시를 Dell 참조 모델과 정합해 클립·보스 좌표 추출 → 연구 CAD 반영 (Claude가 수행 가능) |

## B 경로 절차

1. **부품 주문 (사용자)**: 03JRFX 하판 1개. 예: [AliExpress 03JRFX 신품 표시가 $42](https://www.aliexpress.com/item/1005003988329872.html). 배송지를 **스캔 업체 주소**로 한다(업체 동의 후). 3510/3511/3515/3520/3521/3525/3530/3535 호환 표기 제품이면 된다 — Dell 3D 가이드에서 이 기종들이 같은 하판 메시를 쓴다([`../00-input/dell-official-3d/README.md`](../00-input/dell-official-3d/README.md)). 사용 중인 노트북의 하판은 보내지 않는다.
2. **의뢰 메시지 (사용자 발송)**: 아래 문안. 공개 가격 기준 후보:
   - [Point3D (크몽)](https://kmong.com/gig/521846) — 서울 서초구, PREMIUM "복잡 형상·30 cm 이상" 300,000원/3일, STL 메시. 택배 접수 여부는 페이지에 없음 → 문의 필요
   - [두이엔지 (크몽)](https://kmong.com/gig/347988) — Handy Black Elite / Go!Scan Spark, 택배 가능(발송비 의뢰인, 반송비 업체), PREMIUM 1,000,000원/10일
   - 기타: [3dscanning.co.kr](https://www.3dscanning.co.kr/scanning-services), [inozard](https://inozard.com/MicroScanningServices) (가격 비공개)
3. **수령 후 (Claude)**: 스캔 STL을 `00-input/scan-oem-03JRFX/`에 두면 Dell 참조 모델과 정합, 잔차 지도, 클립 32개·보스 8개 위치/높이 표를 만든다. 스캔 치수는 업체가 제시한 측정 불확도를 넘는 정밀도로 쓰지 않는다.
