# housing-base — Dell Inspiron 15 3525 하판(base cover) 3D 프린트 재설계

> **공개 범위**: 이 저장소는 `housing-base` 폴더의 하판 설계 자료만 담는다. 상위 프로젝트의 다른 폴더는 포함하지 않는다. 장치 식별 정보가 있는 원본 사진과 파생 측정 이미지는 로컬에만 보관하며 문서의 실제 Service Tag 값은 공개하지 않는다. 따라서 일부 과거 문서의 사진 링크는 공개 저장소에서 열리지 않는다.
>
> **재현 범위**: 과거 스크립트 중 일부는 외부 STEP 파일이나 원래 작업 폴더의 절대 경로를 참조한다. 이번 업로드에서는 해당 자료를 추가하거나 CAD·시뮬레이션을 다시 실행하지 않았다. 기존 결과와 제조·조립 검증의 한계는 각 보고서에 따른다.

**목표**: OEM 하판과 기능적으로 동일(나사·클립·흡기·스피커·힌지 인터페이스 완전 호환)하되, 외형만 프로젝트용 형상으로 바꾼 하판을 설계하고 검증한 뒤 발주한다.
**초안**: [00-input/housing-C03-drawings.pdf](00-input/housing-C03-drawings.pdf) (C03, 치수만 있는 엔벨로프)
**이전 리서치**: Codex Astra xhigh (2026-09-24). 결론은 [FLAWS.md](FLAWS.md)에서 항목별로 재검증한다. 그대로 인용하지 않는다.

**2026-09-25 재감사:** 분리 하판 깊이는 평면 투영 약 **227 mm**, 곡면을 따라 약 **229 mm**(사용자 자 측정). 나사 홈 깊이 약 1.7 mm, 클립 높이 약 7 mm. 과거 233 mm와 1.9 mm는 폐기. [v4 수납·1회 외주 가능성 감사](05-verify/ONE-SHOT-FIT-AUDIT.md) 후 [Dell 사진 기반 대체모델/메시 시뮬레이션](05-verify/SURROGATE-SIM-2026-09-25.md)을 수행했다. 옛 CAD의 중앙 상판 결함을 수정했고, v1의 별도 메시 경계는 밀폐 공동으로 재판정해 v2에서 리브를 제거했다. **현재 v2도 OEM 인터페이스·v4 부품 수납이 미검증이므로 발주 금지.** [임시 v4 하판의 최소 게이트](05-verify/TEMPORARY-V4-HOUSING-GATES.md).

**2026-09-26 통합:** [Dell 웹 3D 가이드 참조 감사](05-verify/OFFICIAL-3D-REFERENCE-AUDIT-2026-09-26.md)를 수행해 외곽 **355.32×226.20 mm**, 힌지 노치, 나사 8개 XY를 연구 CAD에 반영했다. v4 연구 STL은 쐐기가 힌지 홈을 메우던 오류까지 수정했다. 이는 웹 가이드용 경량 메시 참조값이지 체결 공차·내부 클립/보스 검증이 아니다. [현재 발주 준비 판정](05-verify/RELEASE-READINESS-2026-09-26.md): **v4도 발주 금지.**

**2026-09-26 후속 통합:** [CAD 개정 v5 + prototype-v4 전자부품 통합 시뮬레이션](05-verify/INTEGRATED-V4-SIM-2026-09-26.md)을 추가했다. 가장자리 나사 5곳의 쐐기 간섭을 국부 홈으로 수정하고 STL 단면/메시를 확인했으나, 선정 후보 HDMI 분배기와 UVC 캡처의 수납 높이가 부족하다. 열 계산은 실측 없는 민감도 시나리오다. **v5도 발주 금지.**

각 단계는 **게이트**를 통과해야 다음으로 간다. 게이트를 통과하지 못하면 이전 단계로 돌아간다.

|---|---|---|---|

| **S1 입력 확정** | C03 PDF 재판독 (좌표계·경사·340×215 정의), 모델·Service Tag 확정, 방향 규약 고정 | FLAWS F1~F3, F6 판정 완료 | ✅ [S1-C03-reading.md](01-research/S1-C03-reading.md) |
| **S2 리서치** | Dell 공식 문서 (Service Manual, Specs, 부품도), 하판 판매 사진 (내부면), 분해 영상, 3520/3525 호환, 공개 CAD/STL | 나사·클립·리브·개구의 위치 후보가 출처와 함께 목록화됨 | 🔄 Dell 3D Guides LOD0 참조 메시 확보 및 [검증](05-verify/OFFICIAL-3D-REFERENCE-AUDIT-2026-09-26.md). 제작용 원본 CAD/공차는 미확보 |
| **S3 실측** | 하판 분리 → 내부면 스캔/수직 촬영, 캘리퍼 측정, 내부 부품 최고점 높이, 정측면 프로파일 | MEASURE-TABLE 필수 항목 전부 채워짐 | 🔄 227/229/7/1.7 mm 사용자 자 측정과 Dell 가이드 메시 355.32×226.20/나사 XY 교차 확인. 곡면·클립 기준면·나사 좌면 Z/공차는 미확정. 실물 스캔 및 비통전 상대물 지그 검수 필요 |
| **S4 설계 방향** | 교체형(일체) vs 결합형(OEM 하판 + 포드) 결정, 외형 경사 방향 결정 | 사용자 승인 | 🔄 일체형 교체 하판 + C03 쐐기 가설. 도전 테이프 단순 대체 및 안전 판정은 철회됨. [D1](03-decision/D1-wedge-replacement-safety.md) / [재감사](05-verify/ONE-SHOT-FIT-AUDIT.md) |
