# 11 — PLA/FDM 후크 13개 복원

`housing-base.zip`의 최신 `10-pla-hinge-clearance`를 기준으로 만든 별도 수정본이다. 원본 07이나 MJF v10.1로 되돌리지 않았다. 설계 파일 생성과 아래의 기하 검사를 완료했으며, 실물 출력·체결·열시험을 완료했다는 뜻은 아니다.

## 전달 파일

- `PLA_body.stl`: 후크 13개와 B12 수납 벽이 한 몸인 교체 하판, 1개.
- `PLA_lid.stl`: 정비 뚜껑, 1개. 원본 10과 바이트 단위로 동일.
- `PLA_floor.stl`: 수납부 아래 바닥판, 1개. 원본 10과 바이트 단위로 동일.
- `base_cover_source.scad`, `params.scad`, `pod.scad`, `fdm_hooks.scad`: 수정 가능한 OpenSCAD 원본.
- `PRINT-ko.md`: 출력 업체 전달 조건. `AUDIT-ko.md`: 검사와 한계.
- `preview_exploded.png`, `preview_hook_detail.png`: 실제 STL에서 만든 미리보기. 주황색은 후크 수정 영역이며 재료를 나눈다는 뜻이 아니다.

## 이번 변경

사진에서 잡았던 13개 걸림 위치를 그대로 사용한다. 기존 1 mm 나일론 수직 스프링을 복사하지 않고, 둘레 방향으로 긴 탄성 팔을 만들었다. 팔 단면은 1.8 × 1.8 mm, 길이는 12개가 18 mm, 뒤 모서리의 1개는 13.2 mm, 뿌리 곡률 반경은 0.9 mm다. 원본처럼 솟은 걸림 끝은 유지하며, 돌출은 변형 요구를 낮추도록 0.6 → 0.35 mm로 줄였다. 이 돌출량의 실제 걸림은 실물 상대 홈에서 확인해야 한다.

팔은 기존 둘레 벽 안에 배치하고 아래에 0.6 mm의 틈을 만들었다. 앞쪽 3개는 팔을 1 mm 낮추고 기둥 아래쪽을 밖으로 꺾어 스피커를 피했다. 후크 기둥 두께는 내부 공간을 위해 1.0 mm로 유지했으며, 긴 팔이 주로 휘게 하는 방식이다. 틈 가공으로 국부 테두리 강성은 달라지며 전체 하중 강도시험은 하지 않았다.

유지한 요소는 본체 일체형 B12 수납 벽, 분리형 바닥판과 정비 뚜껑, 뒤 44 mm의 얇은 힌지 회피 영역, 기존 나사 8개 위치, 팬·환기·배선 및 포트 개구다. 후크 13개는 기존 나사를 보조한다.

## 검사 결과

본체·뚜껑·바닥판 모두 닫힌 단일 메시와 일관된 면 방향을 확인했다. 13개 걸림 형상은 본체에 연결된다. 원본과 새 본체의 후크 주변 밖에서 37,278개 정점·면 중심점을 양방향 비교했으며 가장 큰 표면 거리는 0.000604 mm 미만이었다. 이는 표본 비교이며 전 표면의 수학적 동일성 증명은 아니다.

Dell 가이드 메시의 부품 표면을 0.15 mm 간격 기준으로 샘플링했다. 정지 상태와 0.35/0.5 mm의 안쪽 변형을 가정한 상태에서, 상대 체결 부품인 팜레스트를 제외한 부품과 후크 사이의 침투 표본은 0개다. 본체 자체와도 0.5 mm 변형 조건에서 0.03 mm를 넘는 침투 표본이 없었다. 실제 조립 운동이나 유한요소해석을 대신하지 않는다.

팜레스트에서는 기존 걸림 부근과 교차하는 표본이 남는다. 참조 메시에는 실제 걸림홈 상세·공차가 충분하지 않아 걸림·해제 성공을 판정하지 않았다. 또한 왼쪽 Y136.3 후크는 0.7 mm 변형 가정에서 스피커와 교차한다. 0.5 mm 검사 통과를 더 큰 강제 변형이나 공차 전체의 통과로 해석하면 안 된다.

## 남은 실물 확인

실제 걸림홈 위치와 삽입·해제, 층간 강도와 반복 탈착, 하판 및 수납부 하중, 작동 온도와 PLA 크리프, 힌지 전체 회전 범위, eDP 배선 경로는 아직 실물 검증되지 않았다. 특히 원본 10의 eDP 구멍은 내부 부품 때문에 수직 하강 경로가 막힌 것으로 기록되어 있으며 이번 후크 수정으로 해결하지 않았다. B12 STEP 원본은 제공 ZIP에 없어 전자부품 상세 형상을 새로 검증하지 않았다.

## 재생성

OpenSCAD 2026.09.23의 CGAL로 본체 STL을 생성했다. 본체 소스는 그대로 편집할 수 있다. Python 도구는 `numpy`, `trimesh`, `rtree`, `vtk`가 필요하다.

```text
python build.py <openscad 실행 파일 경로>
python verify_release.py
python check_hooks.py
python check_travel.py
python check_free_space.py
python render_preview.py
```

`design_hooks.py`는 보존한 원본 10에서 파라미터와 본체 소스를 다시 구성하는 보조 도구다. 직접 편집한 본체/파라미터를 덮어쓰므로 필요할 때만 사용한다. 개별 후크 STL과 Dell 참조 메시가 있는 `verification` 폴더는 검사 재현용이며 출력 주문 대상이 아니다. 본체와 별도로 후크를 출력·접착하지 않는다.

원본 10의 검증 결과는 이번 검증과 구별한다. 파일 무결성은 `MANIFEST-SHA256.json`을 사용한다.
